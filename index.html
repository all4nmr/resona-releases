Install

macOS

Open the .dmg, drag Resona into Applications, and launch it. Apple Silicon only (M1/M2/M3/M4).
The app is not notarized, so Gatekeeper warns on first launch (“Resona is from an unidentified developer”). This is expected and the app is safe. Right-click Resona → Open → Open, or run xattr -cr /Applications/Resona.app once from Terminal.

Windows

Run ResonaSetup-0.1.0.exe. It installs the app and the MCP server. It is not code-signed, so SmartScreen may warn — choose More info → Run anyway. No administrator rights needed; you can decline the UAC prompt.

MCP server for AI agents

The MCP server lets AI agents call Resona’s 55 tools directly: spectrum processing, peak picking, protein auto-assignment, J-coupling search, relaxation, DNMR fitting. Windows users are done — the installer already places the server under %LOCALAPPDATA%\Resona\mcp\. macOS users unpack the .tar.gz separately, keeping ResonaMCP and _internal/ in the same folder.

Connect an AI client

Absolute paths only. Restart the client fully after editing. 

{
  "mcpServers": {
    "resona": {
      "command": "C:\\Users\\YOUR_NAME\\AppData\\Local\\Resona\\mcp\\ResonaMCP.exe"
    }
  }
}
macOS path format: /Users/YOUR_NAME/ResonaMCP/ResonaMCP/ResonaMCP. Config file locations — Claude Desktop: %APPDATA%\Claude\claude_desktop_config.json (Windows) or ~/Library/Application Support/Claude/ (macOS); Cursor: ~/.cursor/mcp.json; VS Code: ~/.vscode/mcp.json.
Success looks like these tools appearing: project_status, process_1d, run_batch, assign_protein, j_couplings_1d, dnmr_vt_fit.
Human approval is required
The server cannot bypass your sign-off. apply_labels — the tool that writes labels onto real peaks — refuses to run unless the caller passes both human_confirmed: true and a human_statement. Read-only inspection, review, candidate approval, and dry-run previews are unrestricted. Agents propose; you approve.
